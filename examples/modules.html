WYSIWYG editor

Styly, obrázky i celá obrazovka jsou volitelné moduly. Obrázek vyber ze souboru nebo přetáhni do modalu. Ctrl/Cmd+B, I, K, Z. Ukládá se pouze JSON.

Obrázky se ukládají lokálně přes vývojový server do .pure/uploads. Příspěvek se neodesílá.

Zde se zobrazí strukturovaný JSON.

Editor v angličtině

První editor přebírá češtinu dokumentu. Tento má explicitní locale: en a vlastní překlad počtu slov. Upload i knihovna se připojují samostatnými callbacky.

Resize mimo editor

Táhni za úchyt nebo použij šipky. Escape zruší tažení; Home a End nastaví mezní velikost.

Táhni za název položky. Klávesnice: mezerník nebo Enter, šipky nahoru/dolů, potvrdit; Escape zruší.
